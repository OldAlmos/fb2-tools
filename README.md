# fb2-tools

Небольшой набор скриптов для Linux: проверяет большие коллекции книг в формате FB2 (FictionBook 2) и автоматически чинит типичные повреждения заголовка файла.

Зависимостей нет: нужен только Python 3.9+ (стандартная библиотека).

## Зачем это нужно

Программы для редактирования метаданных и конвертеры иногда записывают заголовок FB2 с неправильной длиной. В результате файл перестаёт открываться в читалках. Типичные случаи:

- обрезанный корневой тег:

  ```xml
  <FictionBook xmlns="http://www.gribuser.ru/xml/fictionbook/2.0" xmlns:l="http://www.w3.org/1999/x<description>
  ```

- «хвост» от старого содержимого после закрывающего тега:

  ```xml
  </description>on>on>on>
  ```

Текст самой книги при этом обычно цел, поэтому такие файлы можно исправить автоматически.

## Состав

| Файл | Назначение |
|------|------------|
| `check_fb2.py` | Рекурсивно проверяет `.fb2` и `.fb2.zip`, выводит только файлы с ошибками. Файлы не изменяет. |
| `fix_fb2.py` | Находит и исправляет известные виды порчи. По умолчанию работает в режиме «пробного запуска». |
| `clean_fb2_bak.sh` | Удаляет резервные копии `*.fb2.bak` после подтверждения. |

## Что проверяет `check_fb2.py`

- корректность XML;
- корневой элемент `FictionBook` в пространстве имён FB2;
- наличие `<description>`, `<title-info>`, `<book-title>` и `<body>`;
- ссылки на изображения без соответствующего `<binary>`.

Это не полная валидация по XSD: проверяется только то, что важно для открытия книги. Строгая проверка по схеме слишком придирчива, многие рабочие книги её не проходят.

## Использование

```bash
# 1. Найти файлы с ошибками
python3 check_fb2.py /путь/к/библиотеке
python3 check_fb2.py /путь/к/библиотеке > errors.txt   # список в файл

# 2. Посмотреть, что будет исправлено (файлы не меняются)
python3 fix_fb2.py /путь/к/библиотеке

# 3. Исправить; оригиналы сохраняются как *.fb2.bak
python3 fix_fb2.py /путь/к/библиотеке --fix

# 4. Перепроверить
python3 check_fb2.py /путь/к/библиотеке

# 5. Удалить резервные копии (спросит подтверждение)
./clean_fb2_bak.sh /путь/к/библиотеке
```

Код возврата `check_fb2.py`: `0`, если ошибок нет, и `1`, если они найдены. Это удобно для скриптов и cron.

### Безопасность

- `fix_fb2.py` без `--fix` ничего не записывает.
- Перед записью исправленный файл проверяется на корректность XML. Если после правки он всё ещё не разбирается, файл остаётся нетронутым и помечается в выводе.
- Работа идёт с байтами, поэтому кодировка файла (UTF-8, windows-1251) значения не имеет.

Перед массовым исправлением на ценной коллекции всё равно сделайте полную резервную копию.

## Установка

```bash
git clone https://github.com/<ваш_логин>/fb2-tools.git
cd fb2-tools
chmod +x check_fb2.py fix_fb2.py clean_fb2_bak.sh
```

Чтобы вызывать скрипты из любой папки, положите их в `~/bin` и добавьте его в `PATH`:

```bash
mkdir -p ~/bin
cp check_fb2.py fix_fb2.py clean_fb2_bak.sh ~/bin/
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```
